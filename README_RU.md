# Rooster для Android — настоящий устанавливаемый APK-проект

Это Android-приложение с собственным Android-манифестом, иконкой, системной оболочкой и локально встроенными файлами Rooster. Никакой веб-сервер или компьютер во время использования не нужен: расписание, стили, скрипты и аватар уже находятся внутри APK. Данные сохраняются в хранилище приложения на самом телефоне.

## Что работает в Android-оболочке

- Запуск как отдельного приложения из списка приложений и с домашнего экрана.
- Локально встроенный интерфейс — открывается без интернета.
- Постоянное хранилище IndexedDB / localStorage внутри WebView приложения.
- Системная кнопка «Назад» закрывает верхнюю открытую панель, затем возвращается из приложения.
- Импорт JSON-резервной копии через системный выбор файла.
- Экспорт резервной копии в `Downloads/Rooster` (Android 10+).
- Подтверждения удаления показаны как системные Android-диалоги.

Важно: экран Rooster использует уже подготовленные HTML/CSS/JavaScript-компоненты, отображаемые в локальном Android WebView. Это гибридное Android-приложение в APK, а не нативно переписанный на Kotlin каждый элемент интерфейса. Но контент поставляется внутри APK и не загружается с сайта.

## Получение APK без установки Android Studio на ваш компьютер

В репозитории уже есть GitHub Actions workflow `.github/workflows/build-apk.yml`. GitHub соберёт APK на своём сервере.

1. Создайте новый репозиторий на GitHub (можно Private).
2. Распакуйте этот архив и загрузите в репозиторий **все файлы и папки проекта**, обязательно включая `.github/workflows/build-apk.yml`.
3. После загрузки GitHub Actions автоматически начнёт сборку. Либо откройте **Actions → Build Rooster Android APK → Run workflow**.
4. Дождитесь зелёной галочки у запуска.
5. Откройте **Releases** в репозитории. Там появится предварительный релиз `Rooster Android build ...`; скачайте файл `app-debug.apk`.
6. Передайте APK на телефон, откройте файл и разрешите Android установку приложений из этого источника, если система попросит.

После установки приложение запускается на телефоне самостоятельно. GitHub нужен только для однократной сборки и получения APK; для повседневного использования он не нужен. В workflow также сохраняется ZIP-артефакт сборки на странице завершённого запуска Actions.

## Сборка локально (необязательно)

Нужны JDK 17, Android SDK 36 и Gradle 9.6.0:

```bash
gradle assembleDebug
```

Готовый файл появится в `app/build/outputs/apk/debug/app-debug.apk`.

## Технические параметры

- Application ID: `com.rooster.mobile.debug` для debug APK.
- Минимальная версия Android: API 26 (Android 8.0).
- Compile SDK: 36.
- Target SDK: 34.
- Java: 17.
- Android Gradle Plugin: 9.5.0.
- Gradle: 9.6.0.

## Данные и резервная копия

Данные расписания хранятся локально внутри приложения. Удаление приложения может удалить эти данные. Делайте резервную копию из админ-раздела до переустановки или переноса на другой телефон. Автоматической облачной синхронизации пока нет.
